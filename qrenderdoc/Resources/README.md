# 源文件

这里的图标大多来自 [fatcow.com](http://www.fatcow.com/free-icons) 的 "Farm-Fresh Web Icons" 图标包。

采用 Creative Commons Attribution 3.0 United States（CC BY 3.0 US）许可。

有些图标有特别说明：

* delete.png 被重命名为 del.png，以避免与 C++ 关键字产生明显冲突。
* flip_y.png 的制作方式是：把 arrow_left.png 旋转成竖直并放在图像上半部分，然后旋转/翻转到下半部分。
* upfolder.png 的制作方式是：把 arrow_up.png 粘贴到 folder.png 上方，然后擦除与文件夹前半部分重叠的所有像素。
* action.png 和 action_hover.png 都基于 document_page_next.png，去掉了小折角并更改了颜色。
* control_reverse_blue.png 只是把 control_play_blue.png 水平翻转。
* control_nan_blue.png 和 control_sample_blue.png 是在 control_cursor_blue 的基础上，把光标编辑掉并替换为相应的符号。control_base_blue.png 不直接使用，但保留下来以防将来需要添加。
