# 提交 issue

感谢你花时间查看提交 issue 的准则！我很乐意帮你处理你的 issue，但格式糟糕或描述不清的 bug 报告要花太多时间去理清，所以你有责任给我尽可能好的机会，让我知道我需要修什么。

:warning: **请注意：你必须使用所提供的相关 issue 模板！** :warning:

使用模板能让我知道你明白一份格式良好的 issue 中应包含什么，并且能让人一眼看到所需的信息。模板并不复杂，很容易填写。如果你不使用模板，你的 issue 将被关闭。

请在提交关于 bug 或崩溃的 issue 时使用 bug report 模板，只在请求添加新功能时使用 feature request 模板。

本文档解释了模板中应包含哪些内容，分为两部分：第一部分针对 bug 报告，第二部分针对功能请求。

:warning: :warning: :warning: :warning: :warning: :warning:
作为所有 issue 的通用规则：RenderDoc 是用于调试你的程序的工具，不是用于侵犯版权的。如果你的问题或请求与捕获并非你所有的受版权保护应用程序有关，那么你将得不到帮助，你的 issue 会立即被关闭。
:warning: :warning: :warning: :warning: :warning: :warning:
