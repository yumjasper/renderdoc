# 计算机术语修正

## 翻译规则

普通操作说明用中文；计算机语言、工具、平台名称、技术缩写、数据类型、代码标识和示例代码保留英文。不把 Python 翻成“蟒蛇”，也不按普通英文单词的含义解释技术缩写。

图形学术语继续保留英文。周围的按钮和操作仍然使用中文，例如“启用 Python 调试”“选择 debugpy 模块的位置”。
