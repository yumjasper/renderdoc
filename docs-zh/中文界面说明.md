# RenderDoc 中文界面说明

## 现在有没有中文版？

有社区维护的中文分支，但这次没有找到官方发布的完整中文语言包。社区版本与本机 1.47 fork 的代码存在版本差异，所以没有用旧版本替换你现有的程序。

本次在你当前源码上新增离线简体中文界面，仍然使用原来的捕获、回放和图形驱动代码。这是本地定制版，不是官方中文版。

参考来源：

- [RenderDoc 官方项目](https://github.com/baldurk/renderdoc)
- [RenderDoc 官方网站](https://www.renderdoc.org/)
- [社区中文分支](https://github.com/wuxianggujun/renderdoc-chinese)

## 打开哪个程序？

启动 [qrenderdoc.exe](D:/Tools/renderdoc/x64/Release/qrenderdoc.exe)。默认显示中文，不用联网，也不用另外下载语言包。请保留输出目录中的配套 DLL 和插件，不要只复制一个 EXE。

## 哪些内容翻成了中文？

当前提取到的 2,549 个界面源文案都已纳入翻译表，另外补充了 Qt 常用按钮及少量原来没有翻译标记的窗口文字。最终翻译表有 2,596 项。

主要包括菜单、启动程序、抓帧设置、文件操作、设置窗口、筛选提示、工具提示、使用小贴士和许多错误说明。翻译经过自动生成、保护校验和关键操作人工调整；没有逐个触发所有错误路径，因此不保证每一条说明都已经人工润色，也不能把这个计数理解为整个软件每个可见字符串都已完全覆盖。

你可能仍然看到英文，分为几种情况：

- Shader、Texture、Buffer、Pipeline、Mesh、Vertex、Pixel、Sampler、Depth、Stencil、Marker、Callstack 等图形学术语有意保留英文。
- Vulkan、D3D11、D3D12、OpenGL、HLSL、GLSL、SPIR-V 等 API 和语言名称不翻译。
- EID、格式枚举、Shader 代码、寄存器、资源名称、文件路径、用户备注和抓帧中的原始数据不翻译。
- 核心库原始诊断、插件自己的界面、外部程序和在线官方文档不属于本次界面翻译范围。
- 第三方 Qt 系统对话框的部分文字可能受系统语言或 Qt 内部文案影响。

例如，Texture Viewer 显示为“Texture 查看器”，Pipeline State 显示为“Pipeline 状态”。既能看懂操作，也方便对照英文教程。

## 字体仍然太大怎么办？

中文化不会自动重置你的个人设置。本次检查时，你的界面字体和等宽字体都设成了“幼圆”，文字缩放为 125%。这些设置本次没有修改。

在“工具 → 设置 → 常规”中，将界面字体改成 Default、Segoe UI 或 Microsoft YaHei UI，等宽字体改成 Default 或 Consolas，文字缩放先用 100%，然后完全退出并重新打开。

文字缩放只放大文字，不会同步放大所有图标和控件。先用 100% 可以减少文字被截断的问题。

## 临时切回英文

在 PowerShell 中执行下面的完整内容。只影响新启动的这个实例，不会永久改变系统环境变量；已有窗口不会自动切换。

```powershell
$oldLanguage = $env:RENDERDOC_UI_LANGUAGE
try {
    $env:RENDERDOC_UI_LANGUAGE = 'en'
    Start-Process 'D:/Tools/renderdoc/x64/Release/qrenderdoc.exe' -WorkingDirectory 'D:/Tools/renderdoc/x64/Release'
} finally {
    $env:RENDERDOC_UI_LANGUAGE = $oldLanguage
}
```

正常双击启动仍然默认中文，除非你另行永久设置了这个环境变量。

## 怎样修改翻译？

翻译表：[zh_CN.json](D:/Tools/renderdoc/qrenderdoc/Translations/zh_CN.json)。左边是原始英文，右边是显示的中文。保留左边内容，只修改右边。

不要删除或改变 `%1`、`%2`、`%n` 等参数占位符。HTML 标签、链接地址和技术标识也要保留。不要把配置键、函数名称或 Shader 代码一起翻译。

运行检查：

```powershell
python 'D:/Tools/renderdoc/build-local/audit_zh.py'
```

翻译表通过 Qt 资源嵌入 EXE。修改后需要重新编译才能生效。编译命令可参考 [编译说明.md](D:/Tools/renderdoc/docs-zh/编译说明.md)，中文构建记录单独保存为 [build-zh-x64-release.log](D:/Tools/renderdoc/build-local/build-zh-x64-release.log)。

实现位置：[ChineseTranslation.h](D:/Tools/renderdoc/qrenderdoc/Code/ChineseTranslation.h)、[qrenderdoc.cpp](D:/Tools/renderdoc/qrenderdoc/Code/qrenderdoc.cpp)、[resources.qrc](D:/Tools/renderdoc/qrenderdoc/Resources/resources.qrc)。Qt 标准翻译入口读取嵌入的 JSON，不依赖在线翻译服务。
